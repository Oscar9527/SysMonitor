# 游戏 HUD 精确位置与横向模式

## 精确屏幕坐标

HUD 设置现在以 X/Y 滑块作为主要操作方式，拖动即可调整位置；右侧数字框保留给需要 1 像素精确微调的用户。坐标以 Windows 虚拟桌面的物理像素为单位，原点是主显示器左上角；位于主屏左侧或上方的显示器可以使用负数坐标。

- 每台显示器独立记忆自己的坐标。
- 优先使用 Windows DisplayConfig 提供的稳定显示器设备路径；不可用时，仅在 GDI 名称和完整屏幕边界都完全一致时使用回退身份。
- 滑块范围会根据当前显示器和 HUD 实际尺寸自动计算，保证整个 HUD 保持可见。
- 混合 DPI 下不会重复缩放坐标；HUD 尺寸按其所在显示器的实际 DPI 计算。
- 如果设置窗口打开后目标程序移动到另一台显示器，应用坐标会被拒绝并刷新当前显示器，防止把旧屏坐标写到新屏。
- 关闭“使用精确屏幕位置”或点击“重置”，只清除当前显示器的精确位置记忆，并恢复原来的百分比定位。托盘的左/中/右快捷位置也会清除当前屏的精确位置。

HUD 继续保持鼠标穿透，因此不直接拖拽悬浮窗；位置通过 HUD 设置中的滑块调整。

## 横向模式

横向模式采用单行布局，只显示：

- CPU 总体占用与温度；
- GPU 占用与核心温度；
- 有效的 Present FPS。

内存、网络和频率不会进入横向布局。没有可信 FPS 样本时，FPS 标签、数值及其间距会一起隐藏，CPU/GPU 数据继续显示。切回垂直模式后，原来的项目顺序、显隐选择和预设会恢复。
