# RTSS 按游戏兼容模式

## 用途

少数旧版 DirectDraw / Direct3D 7 游戏不会产生 PresentMon 能识别的 Present
事件，而且 RTSS 默认配置也可能没有为 DirectDraw 开启检测。SysMonitor 现在提供
一个明确选择、按游戏启用的兼容模式。默认模式没有改变：仍先只读 RTSS 共享内存，
再使用 PresentMon ETW；没有可信帧率时直接隐藏 FPS 行。

## 使用方法

1. 先从托盘菜单选择当前游戏作为悬浮层目标。
2. 打开“悬浮层设置 / Overlay settings”。
3. 在“旧版游戏 FPS 兼容”卡片中确认目标完整路径。
4. 勾选兼容模式并阅读确认提示。
5. 应用后完全退出并重新启动目标游戏。RTSS 本身不需要重启。

关闭兼容模式时，SysMonitor 会恢复首次启用前的原始应用配置；即使游戏已经退出、
移动或卸载，已管理目标仍会出现在列表中供恢复。

## 安全边界

- 只处理用户明确选择的一个可执行文件，不自动跟随前台程序批量创建配置。
- 新建配置只包含 `[Hooking]` 下的 `EnableHooking=1` 和
  `HookDirectDraw=1`；已有配置只改这两个键并保留其他内容。
- 首次修改前保存原始字节和 SHA-256，写入使用临时文件、落盘校验和替换流程。
- 绝不修改 RTSS 的 `Global` 或 `Config`，不启动或重启 RTSS，不加载 RTSS DLL，
  不向游戏进程注入 SysMonitor 代码。
- 两个不同目录中的游戏如果使用相同 EXE 文件名，会对应同一个 RTSS profile。
  SysMonitor 会拒绝第二个同名路径，避免误改另一个游戏。
- 配置被外部程序修改、路径不安全、配置语义重复或恢复校验失败时，操作会停止并保留
  管理记录，不猜测、不覆盖。

## 反作弊说明

兼容模式本质上允许 RTSS 对所选旧版图形 API 使用它自己的 Hook。SysMonitor 不会
因此获得任何反作弊认证，也不能保证所有联网游戏允许 RTSS。使用前应以目标游戏和
反作弊系统的公开规则为准；有疑问时保持关闭。
